# AI Capstone

## Overview

This repository contains my capstone project for the AI-assisted development track.

## Project Purpose

Build a web application that turns user requests into structured, interactive plans — not just plain AI text. Users describe a goal, and the app helps break it into actionable steps they can follow and track.

## Target Users

Students and anyone who wants help turning a goal or idea into a clear, step-by-step plan.

## Problem

AI chat tools often return long, unstructured text. That makes it hard to know what to do next or track progress. This project aims to solve that by presenting plans as organized tasks with a usable interface.

## Planned Features

- **Natural-language input** — describe a goal or request in plain language
- **Structured plan generation** — turn the request into an organized plan with tasks
- **Task list view** — show plan steps in a clear, interactive list
- **Progress tracking** — mark tasks as complete and see overall progress
- **Timing and reminders** — add deadlines or reminders to plan steps (planned)

## Technology Stack

- **Next.js** — React framework for the web application
- **TypeScript** — typed JavaScript for safer development
- **Tailwind CSS** — utility-first styling

## Development Tools

- **Cursor** — AI-assisted development environment used to build this project

## Current Status

The Next.js application has been scaffolded with TypeScript and Tailwind CSS. The next step is building the first UI.
